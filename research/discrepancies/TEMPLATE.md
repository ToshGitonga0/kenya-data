# Discrepancy record template

Copy to `research/discrepancies/<slug>.md` and fill in. Never silently
overwrite conflicting information — if you can't resolve it, document
it as `unresolved`.

- **field**: e.g. `population`
- **entity**: e.g. `Nakuru County`
- **source A**: (registry id + the value it gives)
- **source B**: (registry id + the value it gives)
- **difference**: the actual delta
- **possible explanation**: e.g. different reference years, different
  boundary definitions, methodology difference
- **decision**: which value (if any) was chosen, or "none — left
  unresolved"
- **evidence**: what supports the decision
- **status**: `resolved` | `unresolved`
